# Conditions UI, rules examples, details fix, lower-block rename — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename `hook_mass_t` to `lower_block_mass_t` (schema 12.0.0), make the chart's calculation-details panel work, add ABS/DNV rules examples for the 22689 and 13778 cranes, and let users edit load conditions in the UI.

**Architecture:** Domain edits live in `DocumentEditor` (`core/document_edit.py`) and are validated with `validate_rules_document`; `ModelViewModel` exposes thin slots; a new `ConditionsPanel.qml` binds to them. The rename is one mechanical commit that lands first.

**Tech Stack:** Python 3, pydantic, PyQt6 + QML (Fusion), pytest.

**Spec:** `docs/superpowers/specs/2026-11-09-conditions-ui-examples-rename-design.md`

## Global Constraints

- Python tools: `.venv/Scripts/python.exe`. Tests: `.venv/Scripts/python.exe -m pytest -n auto --dist loadfile`; a single file: add `--no-cov`, drop `-n`.
- Before each commit: `.venv/Scripts/python.exe -m pre_commit run --all-files` passes (black, flake8, mypy, `tests/test_architecture.py`).
- Authored schema: `11.1.0` → `12.0.0`; new file `crane-statics-v12.schema.json`, generated by `schemas/generate_schema.py`; **no migration** of v11 files.
- New examples: `examples/crane_input_22689_abs.yaml`, `examples/crane_input_13778_retracted_dnv.yaml`; invented values carry a YAML comment saying "illustrative".
- ABS rules: `{standard: ABS, crane_class: offshore}`; DNV rules: `{standard: DNV, cabin_above_slewing_bearing: true}`.
- Condition names match `^[A-Za-z][A-Za-z0-9_-]*$` and are unique; a rules document keeps at least one condition.
- Do not rename unrelated `hook_*` names (hook load, hook position, `hook_height_override_m`).
- QML work follows the `qml-ui-development` skill; layering follows `tests/test_architecture.py` (no domain logic in view models).
- Task order is fixed: 1, 2, 3, 4, 5, 6. One branch, one commit per task (more where a task says so).

## Review Focus

- Renaming a condition while the chart or Scene has it selected: selection falls back to the first condition, no crash (Task 5).
- Deleting the last condition, or an edit that makes `validate_rules_document` fail (offboard without wave height / `v_in` / `v_t`; heavy-lift with offboard): refused with a message, document unchanged (Task 4).
- Switching `lift` offboard → onboard and back keeps the hidden wave/`v_in`/`v_t` values (Task 5).
- Undo after a condition edit restores the previous condition values (Task 5).
- A v11 file fails to open with a message that names the rename (Task 1).
- Hovering between two sampled curve points, and a chart that is still streaming, show no stale or wrong trail (Task 2).
- The Conditions tab is absent for a document without `rules` and the Environment panel's wind/motion fields still work there (Task 6).
